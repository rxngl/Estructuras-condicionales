1. Clasificacion de triangulos
Este programa solicita al usuario las longitudes de los tres lados de un triangulo y determina si es equilatero, isosceles o escaleno utilizando estructuras condicionales if, elif y else

2. Año bisiesto
Este programa solicita un año al usuario y determina si es bisiesto. Para realizar la comprobacion utiliza las reglas de divisibilidad entre 4, 100 y 400.

3. Conversor de calificaciones
Este programa solicita una calificacion numerica del 0 al 100 y muestra su equivalencia en letra: A, B, C, D o F.

4. Comparacion de tres numeros
Este programa solicita tres numeros al usuario y determina cual es el numero mayor y cual es el menor mediante estructuras condicionales.

5. Tarifa de entrada
Este programa solicita la edad de una persona y determina el costo de entrada a un parque de acuerdo con su rango de edad.

Estructuras utilizadas
En los cinco programas se utilizan estructuras condicionales de Python
if
elif
else

Tambien se utilizan variables, operadores de comparacion, operadores logicos, entrada de datos mediante input() y conversión de tipos de datos
